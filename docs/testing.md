# 테스트 코드 작성 규칙

## 테스트 제목

`describe`/`it`/`test`의 제목 문자열에는 **한글을 포함**한다.

```ts
it('서버가 없어도 connect/destroy를 견딘다', () => { ... });
it('hex 색상을 파싱한다', () => { ... });
```

`describe`의 대상 함수/모듈명은 영문 그대로 두되, 뒤에 한글 설명을 괄호로 덧붙인다.

```ts
describe('parseColor (색상 문자열 파싱)', () => { ... });
```

`*.test.ts`/`*.test.tsx` 파일은 `pre-commit` 훅이 한글이 전혀 없는 제목을 자동으로 차단한다 ([git-hooks.md](git-hooks.md) 참고).

## 주석

주석이 2줄 이상의 설명이 필요하면 한 줄 주석(`//`)을 나열하지 말고 JSDoc(`/** ... */`)으로 작성한다. 1줄로 끝나는 설명은 그냥 `//`로 충분하다.
